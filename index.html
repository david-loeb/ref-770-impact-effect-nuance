Effect Size

  • Magnitude: how large an effect is
  • Effect size: a standardized measure of effect magnitude
    • Can be compared across outcomes in different units / scales
  • Standardized mean difference: most common effect size measure
    • Difference between participant & comparison group averages, in standard deviation units
    • Cohen’s D & Hedges’ G are most common standardized mean diff statistics
  • Rules of thumb for education field research1:
    • > .20 = large
    • .05–.20 = medium
    • < .05 = small
  • …but everything is context-specific!

Effect Estimates Contain “Noise”

  • Noise: non-systematic error; see appendix for demonstration
    • (bias = systematic error)
  • Is our effect estimate real, or is it just noise?
    • We need a large enough effect estimate that we can be confident it’s coming from a real effect and not just noise
    • “signal-to-noise ratio”
  • Precision: how much our estimates limit noise
  • We can increase precision by:
    • Increasing sample size
    • Adjusting for baseline covariates

Statistical Significance & Power

  • Statistical significance: formalized procedure for evaluating likelihood that effect estimates are “real” and not just noise
  • Statistical power: how likely we are to detect an effect, i.e., decide it’s statistically significant, given a set of factors including:
    • Sample size
    • Effect size
    • Variation in outcomes (after adjusting for baseline covariates)

Minimum Detectable Effect Size

  • Minimum detectable effect size (MDES): re-arrange the power equation to find the smallest effect you are likely to detect given the same set of factors
  • The larger the sample, the smaller your MDES will be
    • But, the more costly your study will be (if collecting data)
  • Practical significance: an effect size that would represent a meaningful change in outcomes
    • No need to try to detect an effect any smaller than that

Moderators: Effect Variation

  • Effects may be different for different subgroups of program participants
  • Moderator: a variable that defines subgroups for whom program effects differ
    • E.g. demographics, SES, pre-program outcome levels, etc.
  • Dosage analysis: moderator analysis that examines if effects differ for people who received different amounts of program services
  • Implementation fidelity can be a moderator; shows if effects varied when prog components were implemented with more fidelity

Mediator: Effect Pathways

  • Mediator: a proximal outcome that affects a more distal outcome
  • Sometimes called a “mechanism” that explains how the program affects the main outcome of interest

  • Can test for mediation by:
    • Estimating effects of prog on mediator & on the more distal outcome
    • See if there’s a relationship between change in the mediator and change in the distal outcome

Meta-Analysis

  • Meta-analysis: statistical synthesis of all evaluations on a certain program type, outcome, or other specified criteria
  • Step 1: systematically gather all published evaluations that meet criteria
  • Step 2: statistically combine effect sizes to get the average effect size & variance
  • Used to:
    1. inform future evaluations
    2. contribute to general knowledge about programs

ra_resample = n => d3.range(n).map(i => {
  const draw = (mean, sd) => d3.randomNormal(mean, sd)()
  const participate = i < n / 2 ? 1 : 0
  const test_score = draw(100, 25)
  const income = draw(75, 25)
  const age = draw(12, 2)
  const prek = d3.randomBernoulli(.45)()
  const y0 = test_score + income * .1 + age * 2 + prek * 5
  return {participate, group: participate === 1 ? "participant" : "comparison",
    test_score, income, age, prek, y0}
})

// R's sample at its own size, and a new draw at the others
